# netsuite-governed-bi (version 1 plugin)

| Path | What it is |
|---|---|
| `skills/netsuite-bi-governance` | The rules every NetSuite analytics answer follows |
| `skills/netsuite-gross-orders` | First dataset skill. Draft, not certified |
| `skills/netsuite-new-dataset` | The guided path for a user creating a new dataset |
| `proposed-queries/` | Query files proposed for certification. Nothing here is certified |

Certified queries are not in this folder yet. They live under `skills/certified-queries/references/` in whichever plugin the organization chooses in Admin settings > Artifacts > Data; that folder's `SKILL.md` must be copied from the plugin Claude creates on Enable, which we do not have yet.

Format source: the Claude Data type's `admin-setup.md`, read 2026-11-22.
